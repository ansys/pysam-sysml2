   Call the API with the specified project ID and build the SysML project from JSON.


   :Parameters:

       **project_id** : :class:`python:str`
           ID of the project to build.

       **resolve_libraries** : :ref:`bool <python:bltin-boolean-values>`, default: :data:`python:False`

       **includes_derived** : :ref:`bool <python:bltin-boolean-values>`, default: :data:`python:True`

       **includes_inherited** : :ref:`bool <python:bltin-boolean-values>`, default: :data:`python:True`
           When ``True``, include inherited memberships and features from the API response.

           The fully built SysML project.
